# NEXUS – Next-Gen AI Summit

A responsive landing page for the fictional **Next-Gen AI Summit 2052**, featuring the event agenda, keynote speakers, testimonials, ticket options, and contact details.

## Features

- Fully responsive layout (desktop, tablet, and mobile)
- Sections: Hero, Agenda, Speakers, Why Attend, Testimonials, Tickets, Contact
- Testimonial carousel and early-bird countdown timer
- Contact and newsletter forms

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- jQuery and Slick Carousel
- Font Awesome and Google Fonts (Syne)

## Project Structure

```
├── images/         # SVG assets
├── index.html      # Main page
├── style.css       # Base styles
├── tablet.css      # Tablet styles
├── mobile.css      # Mobile styles
└── script.js       # Interactivity
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Maknoon-Zia/NEXUS-next-gen-ai-summit.git
   ```
2. Open `index.html` in your browser.

No build step or dependencies to install. Libraries are loaded via CDN.
